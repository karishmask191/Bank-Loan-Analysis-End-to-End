# Excel Dashboard

This folder contains the Excel dashboard for the Bank Loan Analysis project.

## Data Used
- `Finance_1_Cleaned.csv`  
- `Finance_2_Cleaned.csv`  

Both cleaned datasets were analyzed together in Excel to calculate KPIs and build dashboards.

## What Was Done
- KPI calculations using Pivot Tables  
- Dynamic dashboard with Pivot Charts and slicers  
- Analysis of loan performance and risk by grade, state, and verification status  

## File
- `Excel.xlsx` – Dynamic Excel dashboard with interactive filters.
