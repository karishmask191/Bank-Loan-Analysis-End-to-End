# Tableau Dashboard

This folder contains the Tableau workbook for the Bank Loan Analysis project.

## File
- `Tableau.twbx`  
  Interactive Tableau dashboard built on the cleaned combined dataset.

## Features
- Executive summary view  
- Year-wise loan trends  
- Grade & sub-grade risk analysis  
- Verified vs Non-Verified comparison  
- State-wise loan performance  
- Interactive filters and drill-downs  

Open the file using Tableau Desktop or Tableau Public.
