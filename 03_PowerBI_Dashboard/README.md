# Power BI Dashboard

This folder contains the Power BI report for the Bank Loan Analysis project.

## File
- `Power BI.pbix`  
  Interactive Power BI dashboard built using the cleaned combined dataset.

## Features
- Executive KPI summary  
- Good vs Bad loan analysis  
- State-wise and grade-wise performance  
- Dynamic slicers and drill-downs  

Open the file using Power BI Desktop.
